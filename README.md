# SickleCell-Analytics

SickleCell-Analytics is a client-side clinical analytics dashboard and data pipeline designed for sickle cell disease and thalassemia screening programs. The platform ingests raw Complete Blood Count (CBC) output files generated by automated hematology analyzers, standardizes patient data across high-volume screening drives, and automatically applies diagnostic screening algorithms to identify candidates for confirmatory testing.

## Clinical Context and Background

Mass screening programs for hemoglobinopathies—particularly sickle cell trait/disease and beta-thalassemia—are routinely conducted across diagnostic centers, institutional health committees, and community screening camps (such as college drives and district healthcare initiatives). 

Field screening workflows generate large volumes of unstructured or semi-structured multi-column Excel outputs from automated laboratory analyzers. SickleCell-Analytics addresses the operational bottleneck of manual data processing by structuring patient cohorts, computing hematological indices, and isolating high-risk samples for secondary testing.

### Screening Methodology

The system evaluates primary Complete Blood Count (CBC) parameters to determine secondary referral status:

- Haemoglobin (HB)
- Red Blood Cell Count (RBC)
- Mean Corpuscular Volume (MCV)
- Red Cell Distribution Width (RDW)

From these parameters, the platform calculates the Mentzer Index:

$$\text{Mentzer Index} = \frac{\text{MCV}}{\text{RBC}}$$

Patients are shortlisted for High-Performance Liquid Chromatography (HPLC) and sickle solubility confirmation based on the following diagnostic thresholds:

1. **HPLC (HB < 11 g/dL)**: Identifies clinically significant anemia requiring further investigation.
2. **HPLC (Mentzer Index < 13)**: Serves as a validated screening cutoff to differentiate microcytic anemia associated with hemoglobinopathies (such as thalassemia trait and sickle cell variants) from typical iron-deficiency anemia (which classically presents with a Mentzer Index > 13).

## Key Capabilities

- **Automated Ingestion**: Parses raw analyzer spreadsheets directly in the browser using SheetJS, standardizing column mapping and dates across varying report formats.
- **Camp-Wise Segmentation**: Automatically groups records by screening location, institutional camp, or college drive, enabling granular multi-camp management.
- **Reporting and Export**: Generates master registers, camp-specific reports, and dedicated HPLC referral worklists pre-configured with solubility and confirmation fields.
- **Offline Functionality**: Implemented as a Progressive Web Application (PWA) with a custom service worker, allowing health teams in remote or low-connectivity camp settings to operate without internet access.
- **Privacy Controls**: Features an integrated privacy toggle to mask sensitive patient names during clinical reviews or demonstrations.
- **Printable Clinical Summaries**: Provides a standardized clinical report template formatted for physical printing or digital archival.

## Architecture and Technology Stack

The application runs entirely within the client environment to ensure data security and compliance with clinical privacy standards, meaning patient health information is never transmitted to external servers.

- **Frontend Core**: React 18 with Babel standalone for client-side component execution.
- **Spreadsheet Processing**: SheetJS (XLSX) for in-memory data normalization and export generation.
- **Offline Infrastructure**: Service Workers and Web App Manifest (PWA) for local caching and desktop/mobile installation.
- **Design and Layout**: Custom CSS styling optimized for high-throughput laboratory entry, data review, and clinical printing.

## Getting Started

Because SickleCell-Analytics is designed with zero build overhead, it can be launched immediately using any standard web browser or local HTTP server.

### Local Execution

```bash
# Clone the repository
git clone https://github.com/oknidhiiiii/SickleCell-Analytics.git
cd SickleCell-Analytics

# Serve using Python 3
python -m http.server 8000

# Or serve using Node.js
npx http-server
```

Once running, navigate to `http://localhost:8000` in your browser.
